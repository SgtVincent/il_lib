## 训练时按 skill_type / skill_description 重采样

本仓库的 `SkillLabeledIterableDataset` 与 `MTILConditionedIterableDataset` 支持在 segment 级别做带放回的加权重采样，用于缓解 skill 分布长尾（例如 coordinated 仅约 10%）。

### 配置字段

- `data.resample_group_by`: `null` / `skill_type` / `skill_description`
- `data.resample_weights`: `{key: weight}` 的字典，key 为对应的 `skill_type` 或 `skill_description`
- `data.resample_default_weight`: 未在字典中出现的 key 的默认权重（默认 1.0）
- `data.resample_num_segments`: 每个 epoch 采样的 segment 数（默认等于原始 segment 数）

### 示例：提升 coordinated 的采样概率

```bash
python train.py \
  arch=... task=... robot=... data_dir=... \
  data.dataset_class=il_lib.datas.MTILConditionedIterableDataset \
  data.label_level=skill \
  data.resample_group_by=skill_type \
  data.resample_weights="{coordinated: 5.6, navigation: 1.7, uncoordinated: 1.0}"
```

### 示例：对少见的 skill_description 进行 up-weight

```bash
python train.py \
  arch=... task=... robot=... data_dir=... \
  data.dataset_class=il_lib.datas.SkillLabeledIterableDataset \
  data.label_level=skill \
  data.resample_group_by=skill_description \
  data.resample_weights="{pour: 8.0, chop: 4.0, ignite: 6.0}" \
  data.resample_default_weight=1.0
```
